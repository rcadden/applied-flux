# Applied Flux LLC

Website for Applied Flux LLC — a boutique technical consulting firm for marketing and operations leaders.

**Live:** [appliedflux.com](https://appliedflux.com)

## Stack

Vanilla HTML + CSS. No build step, no framework, no npm. Two files: `index.html` + `styles.css`.

Deployed on Cloudflare Pages (static direct upload).

## Local Development

Open `index.html` directly in a browser. No server required.

## Deployment

Push to `main` → Cloudflare Pages auto-deploys to appliedflux.com.  
Push to `dev` → deploys to preview URL.
